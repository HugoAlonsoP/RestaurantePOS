
# KiroPOS

## Objetivo
Desarrollar un software comercial para restaurantes.

## Plataformas
- PC
- Tabletas
- Teléfonos

## Requisitos principales
- Punto de venta
- Gestión de mesas y pedidos
- Comandas para cocina
- Caja y pagos
- Operación sin internet
- Usuarios y permisos
